      How to get a token
      1. On GitHub open Settings › Developer settings › Fine-grained tokens › Generate new token. Use a fine-grained token, not a classic one.
      2. Repository access: Only select repositories › jiayangwong/MyCosplayWebsite (only this repo).
      3. Permissions: Contents: Read and write. Nothing else.
      4. Set an expiry date (for example 90 days), generate it, copy it and paste it below.
